# CodeVenture Python Lab — Prototype V9

V9 adds **Run from file**.

- Select any `.py` file and press **Run file** in the top toolbar.
- Or press the green **▶** beside a file in the Project files list to run it directly.
- **Debug file** debugs the currently selected file.
- The `MAIN` badge still marks the project's default/main file; double-click a file to change it.
- Multi-file imports continue to work because every project file is mounted into `/project` before execution.
- `input()` console bridge, variable table, execution trace, new/import/rename/delete file features remain available.

Open `index.html` in ChatGPT preview, or serve locally for the most browser-like behavior.


## V10 Run controls
- **Run**: runs the project main/entry file (the file marked `MAIN`).
- **Run file**: runs whichever Python file is currently selected in the editor.
- The small `▶` button beside each file still runs that specific file directly.
- **Debug file**: debugs the currently selected file.
